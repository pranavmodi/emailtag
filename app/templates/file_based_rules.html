💡 About File-Based Rules

Rules are stored as individual .txt files in /app/prompts/rules/. Each rule key maps directly to a filename (e.g., ROOT → ROOT.txt). This makes rules easy to version control and edit directly.

Rule Key Format: Use hierarchical keys like ROOT_SCHEDULING_RX for sub-classification rules.
