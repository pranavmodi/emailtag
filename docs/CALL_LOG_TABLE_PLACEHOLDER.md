# Call Log Table Placeholder

## Overview

The `{call_log_table}` placeholder is now available in ALL autorespond templates. It generates a formatted HTML table showing the patient's call history, including date/time, phone number, direction (inbound/outbound), and disposition.

## Placeholder

```
{call_log_table}
```

**Type**: Common placeholder (available to all autorespond types)

**Description**: HTML table of patient call history

## Usage in Templates

### Example Template

```html
<p>Dear {patient_name},</p>

<p>Thank you for your inquiry regarding patient {patient_id}.</p>

<p>Here is your recent call history with our office:</p>

{call_log_table}

<p>If you have any questions, please contact us.</p>

<p>Best regards,<br>
Precise Imaging</p>
```

### Rendered Output

The placeholder will be replaced with an HTML table like:

```html
<table border="1" cellpadding="8" cellspacing="0" style="border-collapse: collapse; width: 100%;">
    <thead>
        <tr style="background-color: #f2f2f2;">
            <th>Date/Time</th>
            <th>Phone #</th>
            <th>Direction</th>
            <th>Disposition</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>12/22/2025 02:30 PM</td>
            <td>(555) 123-4567</td>
            <td style="color: #4CAF50;">⬅️ Inbound</td>
            <td>Appointment Confirmed</td>
        </tr>
        <tr>
            <td>12/20/2025 10:15 AM</td>
            <td>(555) 123-4567</td>
            <td style="color: #2196F3;">➡️ Outbound</td>
            <td>Left Voicemail</td>
        </tr>
    </tbody>
</table>
```

## Data Source

The call log table is generated by:

1. **Fetching call history** via MCP tool `get_patient_call_log`
2. **Based on patient ID** extracted from the email/conversation
3. **Filtered by patient's phone number** (optional - currently shows all calls for the patient)

### Call Log Fie fields

Each call record includes:

- **date_time**: Timestamp of the call (formatted as MM/DD/YYYY HH:MM AM/PM)
- **phone_number**: Phone number that made/received the call
- **direction**: "Inbound" (call to office) or "Outbound" (call from office)
- **disposition**: Call outcome/status (e.g., "Answered", "Voicemail", "No Answer")

## Implementation Details

### Backend

**File**: `app/helpers/call_log_table.py`

**Function**: `generate_call_log_table(patient_id: str, phone_number: str = None) -> str`

**Process**:
1. Calls `get_patient_call_log` MCP tool with patient ID
2. Parses JSON response containing call history
3. Optionally filters by phone number
4. Formats data as HTML table with styling
5. Returns empty string if no calls found

### Frontend

**File**: `frontend/settings2/app/template-config/constants/placeholders.ts`

Added to `common` placeholders (lines 56-60):

```typescript
{
  key: "{call_log_table}",
  description: "HTML table of patient call history (Date/Time, Phone #, Inbound/Outbound, Disposition)",
  example: "<table>...</table>"
}
```

### Agent Integration

The placeholder is automatically populated in:

1. **Lien Agent** (`app/agents/lien_agent.py:1188-1190`)
   - Generates call log when processing lien documents
   - Available in all lien templates (success, modified, invalid, etc.)

2. **Appointment Status Request Agent** (`app/agents/apt_status_req_agent.py:255-260`)
   - Generates call log when responding to appointment inquiries
   - Available in appointment status templates

## Table Styling

The generated table includes:

- **Header**: Gray background (#f2f2f2)
- **Borders**: 1px solid borders with collapse
- **Padding**: 8-10px for readability
- **Direction Colors**:
  - Inbound: Green (#4CAF50) with ⬅️ arrow
  - Outbound: Blue (#2196F3) with ➡️ arrow
- **Font**: Arial, sans-serif, 14px
- **Width**: 100% of container

## Edge Cases

### No Call History

If the patient has no call history, the placeholder will be replaced with an **empty string** (not an error message). This allows templates to gracefully handle cases where call data isn't available.

### Patient ID Not Found

If the patient ID is invalid or "N/A", the call log table will be an empty string.

### MCP Tool Failure

If the `get_patient_call_log` MCP tool fails or returns invalid data:
- Error is logged
- Placeholder is replaced with empty string
- Email still sends (call log is optional data)

### 3. Case Updates

Show call history when responding to case update requests.

## Configuration

### MCP Server

The `get_patient_call_log` tool must be available in the PreciseMCP server:

```python
# precisemcp/server.py
Available tools:
- get_patient_call_log  # Fetches call history for a patient
```

**Port**: Default 8001 (configured in `.env`)

### Environment Variables

No additional configuration needed. Uses existing MCP server connection.

## Testing

2. Trigger an autorespond (lien or appointment)
3. Check the email response for the formatted call table
